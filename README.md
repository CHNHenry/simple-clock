# Simple Flip Clock

一个简洁优雅的翻牌时钟网页，采用黑白配色，具有流畅的翻牌动画和粒子背景效果。

## ✨ 功能特性

- 🕐 **24小时制翻牌时钟** - 显示时:分:秒，每秒自动更新
- 🌐 **网络时间同步** - 从阿里云API获取时间，每小时自动同步
- 🎨 **翻牌动画** - 数字变化时有流畅的3D翻转效果
- ✨ **粒子背景** - 50个星点粒子，自动连接形成星座效果
- 🌊 **浮动效果** - 时钟整体有轻微的上下浮动动画
- 🎭 **黑白配色** - 极致简约的暗色主题
- 📱 **响应式设计** - 完美适配桌面和移动设备
- ⚡ **极致性能** - 轻量级实现，无外部依赖，防内存泄露

## 🛠️ 技术栈

- **HTML5** - 页面结构
- **CSS3** - 样式和动画（Flexbox、Transform、Keyframes）
- **Vanilla JavaScript** - 核心逻辑（无框架依赖）
- **Canvas API** - 粒子背景渲染

## 📦 安装与使用

### 方式一：直接打开

直接用浏览器打开 `index.html` 文件即可。

### 方式二：本地服务器

```bash
# 使用 Python
python -m http.server 8080

# 使用 Node.js
npx serve -l 8080
```

然后在浏览器访问 `http://localhost:8080`

## 🎯 核心特性说明

### 翻牌动画
- 使用 CSS3 `transform: rotateX()` 实现3D翻转
- 上下半部分独立动画，确保数字对齐
- 动画时长 300ms，流畅自然

### 粒子系统
- 自研轻量级粒子引擎（非 particle.js）
- 50个粒子，连接距离 120px
- 自动边界循环，性能优化

### 时间同步
- API: `https://api.m.taobao.com/rest/api3.do?api=mtop.common.getTimestamp`
- 同步间隔: 1小时
- 超时控制: 3秒
- 失败自动回退到本地时间

### 性能优化
- IIFE 封装，避免全局变量污染
- `beforeunload` 事件清理定时器和动画帧
- 翻牌动画元素自动清理
- 粒子数量和连接距离限制
